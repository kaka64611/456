# RG52MINI Music Player

一款专为 Anbernic RG52MINI 掌机设计的全新音乐播放器，参考 AiMusic 界面布局。

## 特性

- **左右分栏布局**：左侧播放列表常驻，右侧频谱/歌词/封面切换
- **中文显示**：完整支持中文文件名和歌词（TTF 字体）
- **实时频谱**：64 频段 FFT 频谱可视化
- **歌词显示**：支持 .lrc 时间轴歌词和 .txt 纯文本歌词
- **5段 EQ**：60/230/910/3.6k/14k Hz 均衡器
- **多种主题**：深蓝/暗黑/紫色/绿色可切换
- **自动播放**：启动自动扫描 BGM 文件夹并播放
- **按键适配**：完整 RG52MINI 按键映射

## 界面布局（AiMusic 风格）

```
┌─────────────────────────────────────────────────┐
│  [Loop] [音量]    ◀ ▶ ⏸    歌名/艺术家         │  顶部栏
├──────────────────────────────┬──────────────────┤
│  频谱 / 歌词 / 封面          │  Playlist        │
│                              │  ──────────────  │
│  歌曲名  00:00 / 03:17      │  歌曲1  03:52   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │  歌曲2  03:17 ◀  │  主区域
│                              │  歌曲3  04:22   │
│  ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓  │                  │
│                              │                  │

```

- **左侧（大区域）**：频谱/歌词/封面，按 T 键切换
- **右侧**：播放列表常驻显示

## 按键映射（RG52MINI）

| 掌机按键 | 功能 |
|---------|------|
| **↑ / ↓** | 播放列表中选择歌曲 |
| **← / →** | 预留（快进/快退备用） |
| **A** | 播放选中歌曲 / 暂停 |
| **B** | 返回 / 退出当前菜单 |
| **X** | 下一曲 |
| **Y** | 上一曲 |
| **L1** | 音量减 |
| **R1** | 音量加 |
| **L2** | 快退 5 秒 |
| **R2** | 快进 5 秒 |
| **Select** | 播放/暂停 |
| **Start** | 切换视图（主界面/文件浏览器/设置） |
| **T键**（键盘） | 切换右侧面板（歌词/频谱/封面） |
| **Select + Start** | 退出播放器 |

> 掌机按键通过 gptokeyb 转换为键盘按键，配置文件为 `rg52mini-music.gptk`

## 安装

1. 将 `rg52mini-music` 文件夹复制到 SD 卡 `/roms/ports/`
2. 将 `RG52MINI Music Player.sh` 复制到 `/roms/ports_scripts/`
3. 音乐文件放在 SD 卡根目录 `/BGM/` 文件夹
4. 歌词文件（.lrc/.txt）与音乐文件同名，放在同一目录

## 编译

```bash
# 本地编译（测试用）
make

# AArch64 交叉编译（RG52MINI）
CC=aarch64-linux-gnu-gcc make
```

## 技术栈

- SDL2（图形/输入/音频）
- SDL2_ttf（中文渲染）
- SDL2_image（图片加载）
- SDL2_mixer（音频播放）
- C11

## 目标平台

- CPU: RK3562 (AArch64)
- 屏幕: 1280x720
- 系统: EmuELEC 4.7
